# HS U.S. History: Reconstruction to Present — Lesson Pages

GitHub Pages-hosted lesson, primary-source, and interactive widget pages for Optima Academy
Online's Grade 10 U.S. History course (CPALMS 2100310), iframed into Canvas.

This repository is a **generated build output**, not hand-edited source. The authored source of
truth lives in `03_Build/week-NN/*.md` in the main course folder; this repo's HTML (and the
paired `canvas-deploy/*.json` files) are generated from that markdown. See the course's
`CLAUDE.md` and `03_Build/skill-remediation-plan.md` for the build process.

## Layout

```
week-01/ .. week-18/   module-map.html, lesson-1.html, primary-source-1.html,
                       lesson-2.html, primary-source-2.html, week-wrap-up.html
                       (week-05 and week-06 have a single primary-source.html instead of two)
widgets/               7 standalone interactive widgets, embedded via <iframe> into lesson pages
```
